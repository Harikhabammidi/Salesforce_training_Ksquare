## Sprint 01 – Data Modeling, Apex & SOQL

##  Overview
This sprint was focused on building core Salesforce development skills through hands-on tasks. I built a custom data model for a Car Service Center use case, practiced Apex fundamentals, ran SOQL queries covering filtering and aggregation, worked on Apex Triggers, and created my first Lightning Web Component using `@wire`.

---

##  Topics Covered
- Data Modeling & Object Relationships
- Apex Fundamentals
- SOQL Querying
- Apex Triggers
- Trigger Handler Pattern
- Lightning Web Components (LWC)

---

##  Key Activities
- Designed and built custom objects (Customer, Vehicle, Appointment, Technician, Invoice) with Lookup and Master-Detail relationships.
- Practiced core Apex concepts (variables, conditionals, loops, lists, maps, classes) using Execute Anonymous.
- Wrote and executed SOQL queries covering WHERE clauses, ORDER BY/LIMIT, relationship queries, and aggregate functions.
- Built an Apex Trigger with validation logic, structured using a separate handler class.
- Created a Lightning Web Component to display custom object records using `@wire`.

---

## Technologies Used
- Salesforce Trailhead Playground
- Apex
- SOQL
- Lightning Web Components (LWC)
- Lightning App Builder
- Developer Console
- Schema Builder

---

##  Outcome
This sprint gave me hands-on grounding in Salesforce development basics — from designing a working data model to writing Apex code, querying data with SOQL, building a trigger with proper handler-class structure, and rendering live record data through a Lightning Web Component.
